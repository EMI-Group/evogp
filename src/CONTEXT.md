# `src/` — install root for the `evogp` Python package
## Intent
This directory exists only to make `src/evogp/` the distribution root (`src` layout).
`setup.py` at the repo root declares `packages=find_packages(where="src")` and `package_dir={"": "src"}`, so the import root is `evogp` (never `src.evogp`) and every import in the repo is written as `from evogp.<subpackage> import ...`.
It contains a single child and no other files; there is no code, no `__init__.py` and no packaging metadata at this level.
## Routing Table
- `src/evogp/` → The entire EvoGP library in two stacks: the torch-native stack (`tree/` data model + the four evaluation engines — fused Triton `tree/fused_engine.py` + `tree/fused_kernels.py`, the dense all-ops route in `tree/dense_engine.py` (which also owns the route policy and `EVOGP_EVAL_MODE`), the specialized per-structure route in `tree/evoxc_engine.py`, and the opt-in merged-graph `batch` route in `tree/batch_engine.py` — plus GP operators, problems, pipeline, packaging-free checks and the pytest suite) and the torch-free functional stack `gp/`. See `src/evogp/CONTEXT.md`.
- `src/evogp/gp/` → The functional, torch-free GP stack (config/state dataclasses, encoding, the operator layer, the numpy evaluator + in-graph problem layer, the `init_gp`/`step`/`run` driver and `smoke.py`), built only on `evoxc` and numpy. See `src/evogp/gp/CONTEXT.md`.
- Evaluation routes are selected by `EVOGP_EVAL_MODE` (`fused` / `dense` / `specialized` / `batch` / `auto`, where `auto` picks `fused` first on a device box from `EVOGP_FUSED_MIN_POP` (16) up while triton is importable and the call fits the fused envelope, then `dense` on that box at pop ≥ 64, and `specialized` everywhere else; `auto` never picks `batch`) and tuned by the `EVOGP_EVOXC_*` / `EVOGP_DENSE_*` / `EVOGP_BATCH_*` / `EVOGP_FUSED_*` knob families — the authoritative list is in `src/evogp/CONTEXT.md`.
- Sibling paths (read-only from here — escalate writes to this node's parent): `../setup.py` (packaging metadata / extras, `version="2.0.0a1"`, `evoxc` + `evox` runtime deps, `torch` optional), `../requirements.txt`, `../README.md` (install + API docs), `../example/`, `../tutorial/`, `../test/`.
